# RentalCar

RentalCar is a web application for browsing and renting cars online.
The project was built with Next.js, TypeScript, and TanStack Query.

## Features

- Browse available rental cars
- Filter cars by:
  - brand
  - rental price
  - mileage

- Infinite loading with Load More button
- Detailed information page for every car
- Rental booking form
- Server-side data fetching
- Responsive image optimization with Next.js Image

## Tech Stack

- Next.js 15
- TypeScript
- TanStack Query
- Axios
- Formik
- CSS Modules

## Pages

### Home Page

- Hero section
- Navigation to catalog

### Catalog Page

- Cars list
- Backend filtering
- Infinite pagination
- Load More functionality

### Car Details Page

- Full car information
- Rental form
- Booking request submission

## Installation

Clone repository:

```bash
git clone <repository-link>
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

## Build

```bash
npm run build
```
